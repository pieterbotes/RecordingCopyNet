Zoom S2S Credentials

Setup instructions
  1. Go to the Zoom App Marketplace and sign in.
  2. Click Develop → Build App, then choose Server-to-Server OAuth.
  3. Give the app a name and click Create.
  4. Copy the Account ID, Client ID, and Client Secret from the app credentials page.
  5. Under Scopes, add: cloud_recording:read:list_user_recordings:admin and cloud_recording:read:list_recording_files:admin.
  6. Click Activate to enable the app.

Auto-Transfer (WebSocket) Disconnected

WebSocket setup instructions
  1. In the Zoom Marketplace, open your S2S OAuth app.
  2. Go to Feature → Event Subscriptions.
  3. Toggle Event subscription on and choose WebSocket method.
  4. Give it a name (e.g., "RecordingCopy").
  5. Click Add Events → Recording → All Recordings have completed (recording.completed).
  6. Click Save — copy the WebSocket Endpoint URL shown (format: wss://ws.zoom.us/ws?subscriptionId=XXX).
  7. Paste it into the field below and click Save.

Google Service Account

Setup instructions
  1. Go to console.cloud.google.com and create a new project (or select an existing one).
  2. Navigate to APIs & Services → Library, search for Google Drive API, and click Enable.
  3. Go to APIs & Services → Credentials, click Create Credentials → Service Account. Give it a name and click Create and Continue. Skip the optional steps.
  4. Click on the new service account, go to the Keys tab, and click Add Key → Create new key → JSON. A .json file will download.
  5. Open the downloaded JSON file and paste its entire contents into the field below.
  6. In Google Drive, right-click your target folder → Share. Paste the service account's client_email (found in the JSON, looks like name@project.iam.gserviceaccount.com) and set the role to Editor. For a Shared Drive, add it as a Content Manager.
  7. Copy the Folder ID from the Drive folder URL:
    https://drive.google.com/drive/folders/<FOLDER_ID>

Domain-Wide Delegation (alternative to Shared Drives)

If you don't have a Shared Drive, you can have the service account impersonate a real user:

  1. In Google Cloud Console, go to your service account → Details. Note the Client ID (numeric).
  2. In the Google Admin Console, go to Security → Access and data control → API Controls, then click Manage Domain Wide Delegation.
  3. Click Add new. Enter the Client ID and the scope: https://www.googleapis.com/auth/drive
  4. Enter the email of the user to impersonate in the field below (must be a user in your domain).
